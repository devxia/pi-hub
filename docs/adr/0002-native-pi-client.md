# ADR 0002：原生 Pi 图形客户端

Status: accepted

## 决定

Pi Hub 管理原生 Pi 文件，外部终端使用独立进程承载公开 SDK 和 InteractiveMode。Pi 拥有 ID、名称、消息、工作目录与分支，Hub 拥有项目、索引、分类及自身回执。

- 打开使用原始记录；用户新的显式打开允许新实例。Hub 不检测普通外部 Pi 占用、不接管进程、不做全局排他。
- 名称对应原生 /name，允许清空。显式 Clone 对应 /clone，从活动 leaf 创建新 ID 并切换同一运行时，原记录保留。
- 原 cwd 丢失时由用户选可用纳管目录仅本次继续，或取消；保留原 ID、文件、header.cwd 和项目归属。
- 宿主加载用户设置、模型、扩展、包、项目资源与信任规则；通过交互登录 shell 继承导出环境，不要求全局 Hub 扩展。
- Hub 退出只断开控制；宿主继续。用户选择“退出会话”时正常结束精确实例，再关闭其终端对象。

## 理由与结果

公开 SDK 能在同一 TUI 运行时执行名称、原生分支复制及会话切换，并保留用户交互资源。只读浏览与来源管理独立于宿主配置。原生 CLI 可继续打开结果，格式及树结构不由 Hub 另行定义。

与 SDK 的组合、版本依据及 RPC 适用边界见 [技术说明](../research/pi-rpc-sdk-managed-processes.md)。精确源身份和请求回执见 [ADR 0004](0004-source-and-request-identity.md)，它们保护操作对象，不授予会话占用权。
