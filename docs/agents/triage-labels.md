# Triage Labels

使用默认分类词汇；本地任务在顶部的 `Status:` 字段写入对应字符串。

| Skill 中的分类 | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求清楚，可交给 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实施或操作 |
| `wontfix` | `wontfix` | 不予处理 |

当 skill 使用这些分类角色时，使用表中的本项目标签。分类与实施进度分别记录，进度约定见 [任务跟踪](issue-tracker.md)。
