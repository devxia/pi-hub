# 领域文档约定

本项目使用单一领域：根目录 GLOSSARY.md 和 docs/adr/，不创建多领域索引。

## 工作依据

先读 [术语](../../GLOSSARY.md)和相关 ADR。功能以[产品规格](../product-spec.md)为完整契约；界面同时读[设计简报](../design-brief.md)和[DESIGN.md](../../DESIGN.md)；Pi/终端集成同时读[集成事实](../pi-integration-facts.md)。当前文件入口统一在[文档索引](../README.md)。

术语表只定义领域概念。ADR 记录最终决定、成立理由及结果；规格记录完整行为；验证记录陈述特定版本的实际证据。三者不能互相替代。

## 变更规则

用户已明确的新决定直接更新正文和相关 ADR，并删除与其冲突的旧决策文件。未确定的实现假设不能写成已确认事实；发现最新要求与实现不符时准确说明差异并完成授权工作。

完成任务应把有效规则合并到现行文档，消除重复规格和悬空引用。不要靠一个“已废弃”标题保留冲突正文。原始测试数据保留版本身份，只由验证索引解释其范围。
